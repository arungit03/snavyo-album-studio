Place flat spread template images in this folder (`.png`, `.jpg`, `.jpeg`, or `.webp`). Black photo areas are detected automatically. You may add a same-name `.json` sidecar to set `id`, `name`, `tags`, `aspectRatio`, `spreadSize`, `minimumSlotArea`, or `notes`.

Run `npm run templates` to regenerate the ignored manifest and transparent overlays. The build also scans the existing `src/assets/templates` folder while those images are migrated.
